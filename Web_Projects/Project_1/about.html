Smart Dost

A lightweight productivity toolkit built with HTML, CSS, JavaScript and Chrome Extension Manifest V3.

Version 1.0.0

Privacy first

  • Notes, tasks, settings and saved entries are stored in chrome.storage.local for the current Chrome profile.
  • No account, login, analytics or custom backend is used.
  • Clipboard access is optional and user-triggered.
  • The QR image is generated by a third-party service; avoid putting confidential content into it.

Smart Dost is an independent personal productivity extension.
